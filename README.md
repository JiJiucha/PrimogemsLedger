# PrimogemsLedger
《原神》原石明细纪录

## 用于记录原石明细的工具

API为我自己抓包
程序是我写了个简单示例后让AI写的

## 功能

记录账号原石明细

## 准备工作

1. 在浏览器打开[米哈游通行证](https://user.mihoyo.com/passport/index.html)并登录
2. 登录成功后，按F12打开开发者控制台
3. 切换到 **console** 选项卡，输入`document.cookie`获取并复制cookie信息**(不包含两侧引号)**
4. 复制输出结果，在与main.py同级的目录下创建文件`cookie.txt`，将cookie信息写入文件

**Cookie 相当于你的登录凭证，请妥善保管，不要分享或上传到公开仓库。**

**工具不会上传任何个人信息**

## 终端运行
> 注：默认您已安装Python至PATH

本工具仅依赖 `requests` 库，可通过以下命令安装：

```shell
python -m pip install requests
```

然后运行

```shell
python ./main.py
```

根据终端提示，可以：

· 选择要抓取的角色（支持序号、UID 或 all 抓取全部角色）
· 决定是否拉取最近三个月的新数据（若本地已有存档，可跳过该步骤直接生成报告）

### 注意事项

· 米哈游接口最多只返回 近 ***3*** 个月 的数据，更早的记录无法直接从官方获取，请定期运行本工具以延长本地存档范围。
· 如遇 Cookie 失效（提示未登录或登录过期），请按「准备工作」中的步骤重新获取并替换 cookie.txt。
· 本工具仅供学习交流使用，请勿过度频繁请求或用于商业用途。
